# Contributing

Additions and corrections are welcome, in whichever way is easiest for you:

- **Suggest a resource** with the [issue form](https://github.com/sr-dash/awesome-heliophysics/issues/new?template=suggest-resource.yml):
  a name, a link, a section and one sentence. No Markdown is needed. When a maintainer accepts it, a
  pull request adding the entry in the right place is opened for you.
- **Open a pull request** that edits `README.md` directly, following the format below.
- **Start a [discussion](https://github.com/sr-dash/awesome-heliophysics/discussions)** for ideas
  that do not fit a single entry, such as a new section.

## What belongs here

- Data archives, software, models, viewers, services, datasets and learning resources for solar,
  heliospheric, magnetospheric or space-weather research.
- Resources that are publicly available and maintained, or that remain useful as they are (for
  example a finished mission's archive).
- Software with a public repository or documentation and an open-source licence.

Not included: individual papers, personal pages without a resource, closed or paid-only services,
and tools that are announced but not yet available.

## Entry format

```markdown
- [Name](https://link) - What it is and what it is for, in one sentence.
```

- Use the resource's own name, and link to its main page or repository.
- Start the description with a capital letter and end it with a full stop. Do not start it with
  the name, and do not use marketing words.
- Keep entries in alphabetical order within each section, ignoring case.
- One resource per pull request is easiest to review; related corrections can go together.

## If you maintain a listed resource

You are welcome to show the listing in your project's README with this badge:

```markdown
[![Listed in Awesome Heliophysics](https://img.shields.io/badge/listed%20in-Awesome%20Heliophysics-fc60a8?logo=awesomelists&logoColor=white)](https://github.com/sr-dash/awesome-heliophysics)
```

Corrections to your own entry are welcome. Moving or renamed links are the most common fix. A weekly
link check reports links that no longer work, and entries whose links stay broken are removed.
